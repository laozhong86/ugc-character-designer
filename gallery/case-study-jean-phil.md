## 二、为什么会火：三条可复用规律

1. **熟脸 + 招牌动作 + 新日常场景 = 无限内容格式**
   「一张认得出的脸 + 一个招牌动作 + 一个新日常场景」，每条视频在梗落地之前
   观众就已经认出来了。这正是本 skill 的公式：招牌发型 + 突出特征 +
   老派真诚着装 + 面无表情 + running bit。
2. **"是真人还是 AI"的悬念本身就是传播燃料**
   观众为了确认真假会重播、放大细节、在评论区争论。未量化，但几乎所有
   病毒式 AI 角色都享受这层免费二次传播。
3. **过程即内容**
   很快，"这个角色怎么做出来的"本身变成了内容赛道——拆解帖、对比帖、
   教程帖二次放大原角色。创作者发布 → 观众分享 → **平台放大** →
   更多创作者入场。Higgsfield 官方亲自下场证明：每个成功案例都在替工具卖广告。

## 五、对本 skill 的意义（背景）

这个 skill 的方法论蒸馏自两篇高收藏长文（@pounddz 的 deadpan 角色公式 +
@arceyul 的播放量经济学，见 `references/sources/`），而 Jean Phil 事件是公式
在真实市场上被验证的最大公开案例：

- **「缩略图辨识 > 精致度」**：Jean Phil 的脸并不精致，但薰衣草西装 + 翘胡 +
  碗盖金发在 feed 里 0.3 秒可辨；Derek 用完全相反的轮廓（遮眼黑发 + 肌肉）
  达到同样效果——**差异化轮廓比美貌重要**。
- **「锁定参考后一切以它为准」**：Jean Phil 每条视频都是同一张脸同一套衣服，
  一致性本身就是梗的一部分；本 skill 的 lock/EDIT 机制把这件事变成硬流程。
- **「角色负责差异，格式负责分发」**：角色提供辨识度，「熟脸 + 招牌动作 +
  新场景」提供可无限复制的分发格式——这正是交接包里 motion_personality
  和推荐格式要交给下游的东西。
- **工具在平民化**：原文给出 $200–300 的完整测试预算；本 skill 把"设计"这一环
  从$299 课程或运气变成可复跑的工程流程（门禁、rubric、进化账本）。
