## 从参考走向原创

借鉴的是设计方法：让发型、轮廓、色板和配件形成清楚的组合。实际设计时，先定义自己的角色用途和人设，再选择新的视觉组合，不直接复用参考角色的身份、脸或整套造型。

1. **拆开看**：分别记下发型形状、身体与服装轮廓、主色和配件，避免把整个人当作一个模板。
2. **重新组合**：从 [170 个造型选项](taxonomy.md) 中挑选与原创人设相符的元素，改变主要锚点与配色关系。
3. **先做定妆**：检查全身造型是否清楚、缩小后能否辨认，再进入多角度设定表和场景参考制作。
4. **检验复用**：在后续场景中核对锁定特征与角色身份一致性；实际效果仍需逐图复核。
