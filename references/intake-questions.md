# S0 捏脸问询流程（多轮次 · 固定流程 · 不得临场自编）

引擎：`scripts/ugc_face.py`（随机与自定义共用同一套兼容规则 + 权重模型）。
原则：
1. **首轮只问一件事：随机捏脸 or 自定义捏脸。**
2. 不从对话语言推断族裔/市场；所有"默认"来自引擎（数据随机权重 + 已锁定条件的亲和度）。
3. 每题都给：引擎推荐的**默认项**（标 Recommended）、若干候选、**随机**、**自定义输入**（ask_user_question 的自由输入）。
4. **分层锁定**：上层选择决定下层可选范围；被上层排除的选项不出现在菜单里（引擎 `menu` 已过滤并给出隐藏原因）。上层改动时，下层不兼容项由引擎自动级联剔除并告知用户。
5. 看图：每个候选附单元素图 `image`（绝对路径），需要时逐张 `display_file`，禁止拼图。

## 第 0 轮（首轮）· 捏脸方式 —— ask_user_question 单题

| 选项 | 后续 |
|---|---|
| 🎲 随机捏脸（Recommended） | → 流程 R |
| 🎛 自定义捏脸 | → 流程 C |
| 🎲 随机 + 锁定几项 | 先问要锁哪些（性别/风格/档位…），再走 R，用 `--lock` 传入 |

可附一个可选题"一次给几个候选？"（1 / 3，默认 3）。

## 流程 R · 随机捏脸

1. 运行：
   ```bash
   python3 <SKILL>/scripts/ugc_face.py random --count 3 [--seed N] [--tier T] [--lock '{"gender":["female"]}'] --slug <slug>
   ```
   算法（可复现，seed 决定一切）：
   - 档位按权重抽（Average 30% / Bold 50% / Extreme 20%）或用户锁定；
   - 按层顺序逐类目抽样：身份 → 风格/发型（锚点优先）→ 身体 → 脸部 → 面部特征/细节；
   - 每一步只在"与已选项兼容"的候选里抽：4 条数据硬冲突 + 软规则（女性不长胡子、帽子不盖高耸发型、光头无发色、无眉不配眉形、细腰不配啤酒肚、巨肌不配蛋形身材、金牙套不叠其它牙齿特征、精灵耳不叠耳朵特征…）；
   - 权重 = 数据内置随机权重（male .67、suits .4、retro .2、lampshade↑、排除 curvy）× 亲和度（族裔→肤色/瞳色，风格→发型/发色/配饰，年龄→灰白发，档位→夸张选项 ×2.5）；
   - **夸张预算**：Average ≤3 / Bold 4 / Extreme 5 个"招牌级"特征，避免堆砌失焦；保证至少 1 个缩略图可读锚点；
   - 自动生成原创人设（20 个 deadpan 原型 × 风格匹配）+ 名字；
   - 组装 = 系统风格提示词（house style：浅灰影棚、正面、面无表情、85mm、editorial 真实质感）+ 每个参数的 `look` 视觉描述 + 人设道具 → `prompt` / `negative`；
   - `--slug` 时写入 `ugc-characters/<slug>-N/`：character.json、face-state.json、prompts/fullbody-1.txt，并返回 `generate`（生图工具调用参数，dest 已填好）。
2. 展示 3 个候选：每个一行中文摘要（`summary[].value` 连接）+ 人设一句话；**直接按 `generate` 调用生图工具出 3 张全身图**，`display_file` 展示。
3. 让用户选：选定 / 换一批（新 seed）/ 锁定其中某几项再随机 / 转自定义微调（以该候选的 face-state.json 为起点，从任一层 `apply` 修改）。
4. 选定后 → S2 `ugc_lab.py card-check` → S3 `log`+`score`。

## 流程 C · 自定义捏脸（6 层，逐层锁定）

```bash
F=<SKILL>/scripts/ugc_face.py; ST=ugc-characters/<slug>/face-state.json
python3 $F init  --state $ST
python3 $F menu  --state $ST --layer L1                       # 本层题目、默认项、候选（已过滤）、隐藏项及原因
python3 $F apply --state $ST --layer L1 --answers '{...}'     # 写入；返回 next_layer 与级联剔除
...  L2 → L6
python3 $F prompt --state $ST --slug <slug>                   # 汇总 + prompt + 生图参数
```

| 层 | 名称 | 类目 | 锁定后对下游的影响 |
|---|---|---|---|
| L1 | 身份基础 | 档位、性别、族裔、年龄 | 档位决定可见选项（Average 隐藏 46 项）；性别决定胡须是否开放、发型权重；族裔→肤色/瞳色默认；年龄→灰白发权重 |
| L2 | 身体 | 肤色、身高、体型、身材比例 | 硬冲突：壮硕×高个；(Bold+) 壮/肌肉/巨肌×短腿/长腿；巨肌×长颈；软：细腰×壮硕/蛋形/啤酒肚 |
| L3 | 风格与发型 | 穿搭风格、发型（招牌锚点）、发色 | 风格→发型/发色/配饰默认；光头跳过发色；高耸发型隐藏帽子 |
| L4 | 脸部轮廓 | 头型、脖子、眼型、瞳色 | 硬冲突：长颈×龅牙 |
| L5 | 面部特征与细节 | 面部特征(≤4，同部位互斥)、胡须、标志性细节(≤2)、配饰(≤3，无配饰独占) | 女性/非二元默认锁定无胡须；无眉×眉形；金牙套×其它牙齿；精灵耳×耳朵特征 |
| L6 | 人设与确认 | 名字、一句话 vibe、垂类、道具、招牌梗（留空 → 自动生成） | — |

每一轮：
1. `menu` → 把本层每个类目做成 ask_user_question 的一题（一次最多 4 题）：
   - 选项 = `options`（引擎已按上层锁定过滤并按亲和度排序），默认项排第一并标 "(Recommended)"；
   - 追加「随机」「自定义输入」，多选类目追加「不选」；更多候选在 `more` 里，用户要看时再列；
   - 题干末尾一句话说明被隐藏的项与原因（`hidden[].reason`）；
   - `skipped` 的类目不问（光头不问发色、女性不问胡须），在汇总里注明。
2. 用户回答 → answers：`"default"` / `"random"` / `"<option_id>"` / `["id1","id2"]` / `{"custom":"中文原话","en":"english phrase"}`。
   - 自定义输入：引擎先尝试映射到已有选项（如"恶魔角"→`hs_horns`）；映射不到则作为自定义描述注入 prompt——**你必须补写 `en` 英文短语**；
   - 用户明确坚持一个被软规则隐藏的选项（如"就要一个有胡子的女性角色"）→ `{"id":"fh_beard","override":true}`；硬冲突与档位可见性不可越过，需改上层。
3. `apply` → 一句话告诉用户 `applied` 与 `cascade_removed`，展示当前已锁定清单（`locked`），进入 `next_layer`。
4. 用户可随时"回到 Lx 修改"：对该层再 `apply`；下游不兼容项会被自动剔除并提示重选。上层变更永远优先，不会被下游已选项阻挡。
5. L6 后 `prompt --slug` → 中文摘要 + 英文 prompt（```prompt-image```）→ 调用 `generate` 出图 → S2/S3。

快捷：用户在任何一层说"剩下的都随机/默认"→ 对剩余各层所有类目 `apply` `"random"` 或 `"default"`。
